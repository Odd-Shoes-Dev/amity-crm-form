1. Overview

This API allows you to manage leads (customers) in the Amity CRM system. You can create, read, update, and delete leads programmatically.

Key Features:

  • Create new leads with all required information
  • Update existing lead information
  • Retrieve lead details individually or in bulk
  • Check for duplicate phone numbers
  • Soft delete leads (mark as lost)
  • Simple JSON responses
  • No authentication required

2. Base URL

https://crm.amityug.com//api/leads.php

3. Authentication

No authentication required. All requests use a default system user. No API keys or tokens needed.

4. API Endpoints

4.1 Create a New Lead

POST /api/leads.php

Headers:

Content-Type: application/json

Required Fields:

Field Type Description
full_name string Lead's full name
phone string Phone number (will be auto-formatted)
source_type string How they heard about us
visit_reason string What they're looking for

Source Type Options:

  • social_media
  • radio
  • referral (requires source_referral_name)
  • broker (requires source_referral_name)
  • walk_in
  • other

Optional Fields:

Field Type Description
gender string Male, Female, Other (default: Male)
address string Physical address
source_referral_name string Required for referral/broker
source_referral_phone string Referral's phone number
general_info string Additional notes

Example Request:

{ "full_name": "John Doe", "phone": "0777123456", "gender": "Male", "address": "Kakoba, Mbarara", "source_type": "referral", "source_referral_name": "Jane Smith", "source_referral_phone": "0777654321", "visit_reason": "Land Inquiry", "general_info": "Looking for 2 acres of land" }

Success Response:

{ "success": true, "message": "Lead added successfully", "data": { "customer_id": 123, "is_existing": false } }

Error Response:

{ "success": false, "message": "Missing required fields: full_name, phone" }

4.2 Update an Existing Lead

PUT /api/leads.php?id={id}

URL Parameters:

Parameter Type Description
id integer Lead ID (required)

Headers:

Content-Type: application/json

Example Request:

{ "full_name": "John Doe Updated", "phone": "0777123456", "lead_status": "qualified" }

Lead Status Options:

  • new (default)
  • contacted
  • qualified
  • prime
  • converted
  • lost

Success Response:

{ "success": true, "message": "Lead updated successfully" }

4.3 Get All Leads

GET /api/leads.php

Query Parameters:

Parameter Type Description Default
page integer Page number 1
limit integer Items per page 20
search string Search by name or phone -
status string Filter by lead status -

Example Request:

GET /api/leads.php?page=1&limit=10&search=John&status=qualified

Success Response:

{ "success": true, "message": "Leads retrieved", "data": { "items": [ { "id": 123, "full_name": "John Doe", "phone": "0777123456", "gender": "Male", "address": "Kakoba, Mbarara", "source_type": "referral", "source_referral_name": "Jane Smith", "source_referral_phone": "0777654321", "lead_status": "new", "created_at": "2024-01-15 10:30:00" } ], "pagination": { "current_page": 1, "per_page": 10, "total": 50, "total_pages": 5 } } }

4.4 Get a Single Lead

GET /api/leads.php?id={id}

URL Parameters:

Parameter Type Description
id integer Lead ID (required)

Example Request:

GET /api/leads.php?id=123

Success Response:

{ "success": true, "message": "Lead found", "data": { "id": 123, "full_name": "John Doe", "phone": "0777123456", "gender": "Male", "address": "Kakoba, Mbarara", "source_type": "referral", "source_referral_name": "Jane Smith", "source_referral_phone": "0777654321", "lead_status": "new", "created_at": "2024-01-15 10:30:00" } }

Error Response:

{ "success": false, "message": "Lead not found" }

4.5 Check Phone Number

GET /api/leads.php?check_phone={phone}

URL Parameters:

Parameter Type Description
check_phone string Phone number to check

Example Request:

GET /api/leads.php?check_phone=0777123456

Success Response (Phone exists):

{ "success": true, "message": "Phone exists", "data": { "exists": true, "customer": { "id": 123, "full_name": "John Doe", "phone": "0777123456" } } }

Success Response (Phone available):

{ "success": true, "message": "Phone available", "data": { "exists": false } }

4.6 Delete a Lead

DELETE /api/leads.php?id={id}

Note: This is a soft delete. The lead will be marked as "lost" but not permanently removed from the database.

URL Parameters:

Parameter Type Description
id integer Lead ID (required)

Example Request:

DELETE /api/leads.php?id=123

Success Response:

{ "success": true, "message": "Lead marked as lost" }

Error Response:

{ "success": false, "message": "Lead not found" }

5. Usage Examples

5.1 Using cURL

Create a Lead:

curl -X POST https://crm.amityug.com/api/leads.php \ -H "Content-Type: application/json" \ -d '{ "full_name": "John Doe", "phone": "0777123456", "source_type": "referral", "source_referral_name": "Jane Smith", "visit_reason": "Land Inquiry" }'

Get All Leads:

curl -X GET https://crm.amityug.com/api/leads.php

Get a Single Lead:

curl -X GET https://crm.amityug.com/api/leads.php?id=123

Update a Lead:

curl -X PUT https://crm.amityug.com/api/leads.php?id=123 \ -H "Content-Type: application/json" \ -d '{"full_name": "John Doe Updated", "lead_status": "qualified"}'

Check Phone:

curl -X GET https://crm.amityug.com/api/leads.php?check_phone=0777123456

Delete a Lead:

curl -X DELETE https://crm.amityug.com/api/leads.php?id=123

Check Phone:

async function checkPhone(phone) { const response = await fetch(`https://crm.amityug.com/api/leads.php?check_phone=${phone}`); const data = await response.json(); console.log(data); }

Delete a Lead:

async function deleteLead(id) { const response = await fetch(`https://crm.amityug.com/api/leads.php?id=${id}`, { method: 'DELETE' }); const data = await response.json(); console.log(data); }

5.3 Using Python (requests)

Installation: pip install requests

Create a Lead:

Get All Leads:

def get_leads(): response = requests.get(base_url) print(response.json())

Get a Single Lead:

Update a Lead:

def update_lead(id): data = { "full_name": "John Doe Updated", "lead_status": "qualified" } response = requests.put(f"{base_url}?id={id}", json=data) print(response.json())

Check Phone:

def check_phone(phone): response = requests.get(f"{base_url}?check_phone={phone}") print(response.json())

Delete a Lead:

def delete_lead(id): response = requests.delete(f"{base_url}?id={id}") print(response.json())

Run All Examples:

create_lead() get_leads() get_lead(123) update_lead(123) check_phone("0777123456") delete_lead(123)

5.4 Using PHP (cURL)

Create a Lead:

<?php $base_url = "https://crm.amityug.com/api/leads.php"; function createLead() { global $base_url; $data = [ "full_name" => "John Doe", "phone" => "0777123456", "source_type" => "referral", "source_referral_name" => "Jane Smith", "visit_reason" => "Land Inquiry" ]; $ch = curl_init($base_url); curl_setopt($ch, CURLOPT_RETURNTRANSFER, true); curl_setopt($ch, CURLOPT_POST, true); curl_setopt($ch, CURLOPT_HTTPHEADER, ['Content-Type: application/json']); curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data)); $response = curl_exec($ch); curl_close($ch); echo $response; }

Get All Leads:

function getLeads() { global $base_url; $response = file_get_contents($base_url); echo $response; }

function getLead($id) { global $base_url; $response = file_get_contents("$base_url?id=$id"); echo $response; }

Update a Lead:

function updateLead($id) { global $base_url; $data = [ "full_name" => "John Doe Updated", "lead_status" => "qualified" ]; $ch = curl_init("$base_url?id=$id"); curl_setopt($ch, CURLOPT_RETURNTRANSFER, true); curl_setopt($ch, CURLOPT_CUSTOMREQUEST, "PUT"); curl_setopt($ch, CURLOPT_HTTPHEADER, ['Content-Type: application/json']); curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data)); $response = curl_exec($ch); curl_close($ch); echo $response; }

Check Phone:

function checkPhone($phone) { global $base_url; $response = file_get_contents("$base_url?check_phone=$phone"); echo $response; }

Delete a Lead:

function deleteLead($id) { global $base_url; $ch = curl_init("$base_url?id=$id"); curl_setopt($ch, CURLOPT_RETURNTRANSFER, true); curl_setopt($ch, CURLOPT_CUSTOMREQUEST, "DELETE"); $response = curl_exec($ch); curl_close($ch); echo $response; }

Run All Examples:

createLead(); getLeads(); getLead(123); updateLead(123); checkPhone("0777123456"); deleteLead(123); ?>

5.5 Using Postman

Setup Instructions:

  1. Open Postman and create a new collection called "Amity CRM"
  2. Create an environment variable:
    • Variable name: base_url
    • Value: https://crm.amityug.com/api/leads.php
  3. Add requests for each endpoint

Sample Requests:

POST - Create Lead:

URL: {{base_url}}
Method: POST
Headers: Content-Type: application/json
Body: Raw JSON
{ "full_name": "John Doe", "phone": "0777123456", "source_type": "referral", "source_referral_name": "Jane Smith", "visit_reason": "Land Inquiry" }

GET - All Leads:

URL: {{base_url}}
Method: GET

GET - Single Lead:

URL: {{base_url}}?id=1
Method: GET

PUT - Update Lead:

URL: {{base_url}}?id=1
Method: PUT
Headers: Content-Type: application/json
Body: Raw JSON
{ "full_name": "John Doe Updated" }

DELETE - Delete Lead:

URL: {{base_url}}?id=1
Method: DELETE

6. Response Codes

Code Description
200 Success - Request completed successfully
400 Bad Request - Missing required fields or invalid data
404 Not Found - Lead doesn't exist
405 Method Not Allowed - HTTP method not supported
500 Server Error - Something went wrong on the server

7. Error Handling

All errors return a consistent format:

{ "success": false, "message": "Error description here" }

Common Error Messages:

  • "Missing required fields: full_name, phone"
  • "Lead not found"
  • "Invalid source_type. Allowed: social_media, radio, referral, broker, walk_in, other"
  • "Referral/Broker name is required for referral"
  • "No fields to update"

8. Field Reference

Field Required Type Description
full_name Yes string Lead's full name
phone Yes string Phone number (auto-formats Ugandan numbers)
gender No string Male, Female, Other (default: Male)
address No string Physical address
source_type Yes string How they heard about us
source_referral_name No* string Required for referral/broker
source_referral_phone No string Referral's phone number
visit_reason Yes string What they're looking for
general_info No string Additional notes
lead_status No string new, contacted, qualified, prime, converted, lost
* Conditional Required: source_referral_name is required when source_type is referral or broker.
